# tr3-test-feed

Тестовый товарный фид для проверки кампаний в Yango Ads / AIR.

**Все данные фейковые** — цены, ссылки на карточки товаров, GTIN, остатки и наличие
сгенерированы скриптом и не соответствуют реальным магазинам. Картинки — генеративные
баннеры из внутреннего теста, тайтлы написаны под то, что на них изображено.

## Что внутри

- `feed_tr3_test.xml` — фид в формате Google Merchant (RSS 2.0, namespace `g:`), 80 офферов
- `images/{manuka,defacto,fresh_scarf,sporthink}/*.jpg` — 4 бренда по 20 картинок
- `build_feed.py` — генератор фида

Прямая ссылка на фид:

```
https://raw.githubusercontent.com/chubarkul/tr3-test-feed/main/feed_tr3_test.xml
```

## Состав

| Папка | Бренд | Категория |
|---|---|---|
| `manuka` | Manuka | женская одежда, сумки, аксессуары |
| `defacto` | DeFacto | базовая одежда, детское, аксессуары |
| `fresh_scarf` | Fresh Scarf | шали / платки (все с размерами) |
| `sporthink` | Sporthink | спортивная обувь и одежда |

Наличие разнесено намеренно: ~85% офферов `in stock`, остальные `out of stock` и
`preorder` — чтобы проверить реакцию движка на недоступные товары. У каждого третьего
оффера есть `sale_price` с периодом действия.

## Пересборка

Поменять `IMAGE_BASE` в `build_feed.py` (если картинки переедут на другой хостинг) и:

```bash
python3 build_feed.py
```
