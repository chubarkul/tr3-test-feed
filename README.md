# tr3-test-feed

Тестовый товарный фид для проверки кампаний в Yango Ads / AIR.

**Все данные фейковые** — цены, ссылки на карточки товаров, GTIN, остатки и наличие
сгенерированы скриптом и не соответствуют реальному магазину. Картинки — генеративные
баннеры из внутреннего теста, тайтлы написаны под то, что на них изображено.

Текущая версия (24.09.2026): **Сербия, магазин bpolar, 20 офферов, валюта RSD.**
Прошлая турецкая партия (70 офферов, 5 брендов) удалена — её можно достать из истории
коммитов, ссылка на фид при этом не менялась.

## Что внутри

- `feed_tr3_test.xml` — фид в формате Google Merchant (RSS 2.0, namespace `g:`), 20 офферов
- `images/bpolar/*.jpg` — 20 картинок
- `build_feed.py` — генератор фида

Прямая ссылка на фид (не меняется между версиями):

```
https://raw.githubusercontent.com/chubarkul/tr3-test-feed/main/feed_tr3_test.xml
```

## Состав

Магазин мультибрендовый, бренд задаётся на уровне оффера:

| Бренд | Офферов | Категории |
|---|---|---|
| Fred Perry | 5 | поло, футболки, харрингтон |
| Eastpak | 3 | чемоданы 34 / 90 / 121 л |
| Stance | 2 | носки |
| Scholl | 2 | сабо |
| Crocs, On, Puma, Moon Boot | по 1 | обувь |
| New Era, Nike | по 1 | шорты |
| K-Way | 1 | стёганая куртка |
| Wall Notion | 1 | детская футболка |

Тайтлы и `product_type` сербские, как и текст на баннерах. Наличие разнесено:
19 офферов `in stock`, 1 `out of stock`. У 8 офферов есть `sale_price` с периодом
действия. Цены и наличие детерминированы от `g:id`: пересборка фида не перетасовывает
цифры.

## Пересборка

Поменять `IMAGE_BASE` в `build_feed.py` (если картинки переедут на другой хостинг) и:

```bash
python3 build_feed.py
```
